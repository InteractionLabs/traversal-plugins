# Traversal for Codex

Connects Codex to Traversal's remote MCP server so your agent can investigate production incidents, find root causes, and suggest fixes using your observability data. It also adds skills that teach the agent how to run investigations, follow up on findings, and share results.

## Setup

1. Install the plugin. See the [repository README](../../README.md) for install steps.
2. Sign in to Traversal with your work email when Codex prompts you. No API key is needed.

Then ask your agent about a production issue, for example: "Why is checkout-service returning 500s since 14:00?"
