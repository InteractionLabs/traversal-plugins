# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to [security@traversal.com](mailto:security@traversal.com). Don't open a public GitHub issue for a security problem.

Include as much as you can:

- The plugin and agent affected (Claude Code, Cursor, or Codex) and the plugin version
- Steps to reproduce, or a proof of concept
- The impact you expect

This covers the plugins in this repository and the Traversal service they connect to.

## Supported versions

Security fixes are released for the latest version of each plugin.

## More information

See the [Traversal Trust Center](https://trust.traversal.com/) for security and compliance documentation.
